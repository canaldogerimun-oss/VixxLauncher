# VixxLauncher 0.1.0 — base de desenvolvimento

Fork independente baseado no ZalithLauncher. Não é oficial nem endossado pelos mantenedores originais.

## Identidade e alterações desta etapa
- Nome exibido: Vixx Launcher
- Nome do artefato: VixxLauncher
- applicationId: `com.vixx.launcher` (debug recebe o sufixo `.debug`)
- Namespace interno preservado para reduzir risco de quebrar referências Kotlin/Java nesta etapa.
- Paleta roxo profundo/violeta, incluindo temas claro e escuro.
- Ícone provisório V em roxo, gerado para esta cópia.
- Versão de desenvolvimento: `0.1.0`
- Nenhuma otimização de FPS foi aplicada ainda.

## Compilação
Use a versão de JDK, Android SDK e NDK exigida pelo projeto e siga o workflow de CI incluído. Para primeiro teste, compile uma variante debug e confirme inicialização, controles, GL4ES e conta local antes de qualquer alteração de desempenho.
