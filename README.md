🟣 Sobre o projeto

O VIXX Launcher é um projeto de launcher para executar Minecraft: Java Edition em dispositivos Android.

A proposta é trazer uma experiência inspirada nos launchers de computador, combinando uma interface moderna, gerenciamento do jogo, personalização e suporte à experiência com teclado e mouse.

Mais do que uma simples interface, o VIXX busca construir uma experiência própria para quem gosta de jogar Minecraft Java no Android.

✨ O que estamos construindo

- 🎮 Dashboard VIXX: interface própria, moderna e organizada.
- 📚 Biblioteca: gerenciamento e acesso às instalações do jogo.
- 🧩 Mods: organização e gerenciamento de modificações.
- 🎨 Skins: espaço dedicado à personalização.
- 👤 Contas: gerenciamento de perfis.
- 🎛️ Controles: personalização da experiência de jogo.
- ⚙️ Desempenho: ferramentas e ajustes voltados à experiência de execução.

Os recursos estão em diferentes estágios de desenvolvimento. Nem todos estão disponíveis na versão atual.

🎨 Identidade visual

Uma identidade construída em torno de três elementos:

- Preto profundo.
- Roxo neon.
- Prata e branco.

Interface minimalista, futurista e inspirada na organização de softwares para PC.
